# Zephyr

Zephyr is a small web experience inspired by the [Cloud Resume Challenge](https://cloudresumechallenge.dev/docs/the-challenge/azure/).
The project consists of a Vite frontend and a C# Azure Functions
backend. The backend exposes a simple visitor counter backed by Azure
Table Storage using Azure.Data.Tables.

## Tech Stack
- Vite
- TypeScript
- React
- Three.js
- C# / .NET
- Azure Functions
- Azure Table Storage
